# 0.8.4 修复清单（“已移植但用不了”的功能）

本版**没有新增界面**，只修已有功能。滚轮的尺寸 / 位置 / 圆盘外观**未改**（已还原）。

APK：`app/build/outputs/apk/debug/app-debug.apk`（versionName 0.8.4 / versionCode 84）

## 1. USB Bit-perfect

| | 之前 | 现在 |
|---|---|---|
| 没 DAC 时 | 设置里一开开关，ExoPlayer 就被 `volume = 0`，进度条在走但**完全没声** | 只有原生等时通道确认在跑（`UsbUac2Stream.isStreaming`）才静音；否则继续走系统输出，有声 |
| 打开开关 | 会去 `/sdcard/Download/lmflac` 等目录挑一个**最大的文件**直接播进 DAC（用户没点过的歌） | 开关只写偏好，不启动任何音频流 |
| 暂停 / 切歌 / 退出 | 原生流不会停，DAC 继续把上一首放完，界面已经在下一首 | `PlaybackService.syncPassthrough()` 跟随播放状态启停 |
| 每首歌 | `onTracksChanged` 都会 `clearMixer()` + 重新申请 6 档 mixer → 歌曲边界断音/爆音 | 只在开关变化 / 设备插拔时协商 |

**验证**：不插 DAC，打开开关 → 放一首歌，应该正常有声；插 DAC 再放，状态横幅显示直通进行中。

## 2. DSD（.dsf/.dff）

- 转 PCM 改成**流式**：峰值内存与曲长无关（旧实现整轨进内存，3 分钟 DSD64 约 630MB，必然 OOM）。
- 开着 USB 直通点 DSD 曲目时，不会再被直通分支抢走（以前直接交给 ExoPlayer 解 `.dsf` → 必失败）。
- DSD 文件里的 ID3 标签（歌名/艺术家/专辑）现在能读到（以前提前 `return`，永远显示文件名）。
- 转换失败会删掉半成品缓存文件，不会下次被当成“已转好”直接播。

**验证**：放 `/sdcard/Download/lmflac/000-dsd-test.dsf`（我改名了，原 `dsd64-1khz-stereo.dsf`）→ 应显示 “DSD64 1bit/2822.4kHz”，点播放有 1kHz 测试音。

## 3. 音量标准化（ReplayGain）

- 之前**恒为 null**：曲库只扫 SAF 文件夹，`content://` 没有物理文件，jaudiotagger 那段根本不执行。
- 现在扫描时直接解析文件头：FLAC 的 `VORBIS_COMMENT`、MP3 的 `ID3v2 TXXX`，并做一次性回填。
- 设置页「音量标准化」下面显示**当前曲目的增益值**（如 `本曲 -6.5 dB · 已应用`），没有标签会说没有。

**验证**：`/sdcard/Download/lmflac/RG - Tagged Test.flac` 我写了 `REPLAYGAIN_TRACK_GAIN=-6.50 dB`（测试完建议删掉）。放它 → 设置页应显示 -6.5；开关切到关闭，声音应变大。
另外整库回填只跑一次（`replayGainBackfillV1`），所以现在库里 452 首里只有这一首有标签是正常现象。

## 4. PC 有线音箱

- `stop()` 以前只 `Thread.interrupt()`，而线程卡在 `accept()` 上唤不醒 → 端口一直占着 → 再开就 `bind failed: EADDRINUSE`。
- 现在 stop 会 close 监听 socket + 客户端 + AudioTrack，端口真正释放。
- 说明里的方向也改了：手机是**服务端**，电脑端要 `adb forward tcp:8899 tcp:8899`（`adb reverse` 会先占住手机 8899）。
- 设置行下面独立显示状态：未启用 / 正在启动 / 监听中 / 电脑已连接 / 启失败原因（不再借用“音频输出”那条共享横幅）。

**验证**：开 → 关 → 再开，连点三次不应再出现 EADDRINUSE；`adb forward tcp:8899 tcp:8899` 后电脑连 `127.0.0.1:8899` 发 PCM 应有声。

## 5. 云备份

- 导出时判断歌词目录用了 `"\\lyrics\\"`（反斜杠），Android 路径是 `/` → **所有歌词被写进 `covers/`**，恢复回来歌词全丢。现在按相对路径。
- 恢复以前直接覆盖正在使用的 `library.db`，SQLite 连接会把旧内容反写回去 → “提示恢复成功但什么都没变”。现在两阶段：先解包到 `files/restore-pending`，**下次启动**在打开数据库之前落盘。
- 导出用 `VACUUM INTO` 取一致快照；打包/解包移到 IO 线程（以前在主线程，大库会卡到 ANR）。

**验证**：导出 → 改几首收藏 → 恢复 → **完全退出 App 再打开** → 收藏回来。

## 6. 刮削 / 歌词

- 网易云封面 `http://` 链接升级成 `https://`（targetSdk 36 默认禁明文，以前这类封面直接失败）。
- 歌词改用 weapi 加密接口（旧 `/api/song/lyric` GET 常返回 200 但空词），并合并翻译行。
- 播放页打开一首没歌词的歌会**自动联网补一次**（同曲只请求一次），不再是死等批量刮削。
- 配图要求歌名 + 歌手同时匹配（以前只看歌名，短名歌容易配错图）。
- LRC：`[ti:] [ar:] [al:] [by:] [offset:]` 不再当歌词行；`[offset:]` 生效；GBK / UTF-16 的 `.lrc` 能正确解码。
- 封面写入改成“临时文件 → 校验 → 原子替换”，选到坏图不会把旧封面删掉。

**验证**：设置 → 立即刮削（现在有“停止”）；找一首之前没封面的看是否补上。

## 7. 控件补齐

- **淡入淡出**：以前整行点一下在 `900ms ↔ 关` 之间循环。现在点开是明确选项：关 / 300 / 600 / 900 / 1200 / 1500ms。
- **睡眠定时器**：以前点一下 30→60→90→关 循环、且到点后界面永远停在“N 分钟后暂停”。现在点开选 关/15/30/60/90 分钟，到点界面自动回“未设置”。
- **刮削**：进行中有「停止」。
- **批量导入 LRC**：结果分「已导入 / 没匹配上 / 读取失败」，不再只有一句“已导入 N 个”。
- **悬浮歌词**：按文案只在**曲库页**显示（以前乐单/喜欢/设置页都会浮出来挡住标题）；没歌词时显示「♪ 歌名」而不是完全不出现。
- **返回键**：关于页 / 语言弹窗 / 乐单菜单按返回不再直接退出 App。
- **设置页**：滚动位置不再每次回到顶部；网易云 Cookie 输入不再每敲一个字符写一次磁盘。
- 设置页那批写死中文的行改成资源，四语言（en/zh/ja/ru）各 245 条 key，无缺失。
